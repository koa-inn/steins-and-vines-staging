# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each was discovered through failure this session or the last.

- [ ] CONSTRAINT: **Never run a blanket `git checkout -- .` / `git restore .` / `git stash` in this tree.** The owner keeps uncommitted work here (`links.html`). This session a blanket checkout, used to undo build-stamp churn, destroyed it. Mitigation: restore build artifacts by explicit path list only (the stamped HTML files, `js/*.min.js`, `js/main.js`, `js/admin.js`, `css/*.min.css`), never the whole tree; check `git status` for owner-modified files first.
- [ ] CONSTRAINT: **A commit chain must gate on the test result, not just run the tests.** `set -e` does not catch a failing `npm test` piped through `grep`. Two commits went out with failures this session (one amended, one benign but unverified at commit time). Mitigation: capture the `Tests:` line, `grep -q failed` on it, and `exit 1` before `git commit` — the `gate()` helper used later in the session does this.
- [ ] CONSTRAINT: **`npm audit fix --omit=dev` prunes devDependencies from local `node_modules`** (jest, supertest vanish; 17 suites "cannot find module"). The committed lockfile is unaffected. Mitigation: run `npm install` afterwards before testing; never treat suite-load failures after an audit fix as a code regression.
- [ ] CONSTRAINT: **Staging/production share ONE Google Sheet and ONE Apps Script deployment.** Any admin write is a live write. (Carried forward.)
- [ ] CONSTRAINT: **A running page does not reload after a deploy; a `navigate` to the same URL can serve cached HTML with the old stamp.** Assert the executing bundle via `performance.getEntriesByType('resource')` inside the page (or iframe) and add a fresh query string to force a load. (Carried forward + extended.)

**Do not proceed until all boxes are checked.**

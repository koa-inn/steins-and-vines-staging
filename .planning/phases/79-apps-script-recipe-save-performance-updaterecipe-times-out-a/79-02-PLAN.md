<objective>
Add the four pure helper functions that D-04 (skip the ingredient rewrite when nothing changed)
and D-05 (hoist id minting out of the insert loop) will be built on, and — crucially — give them
**real local test coverage**, written first.

Purpose: `apps-script/adminApi.gs` has zero test coverage of any kind (79-PATTERNS.md confirmed:
no `.gs` test shim, no mock `SpreadsheetApp`, and `zoho-middleware/__tests__/recipes.test.js` mocks
`axios.post` outright so it never reaches `updateRecipe`). CLAUDE.md rule 3 ("write a regression
test FIRST") therefore cannot be honoured for the Sheets round-trips themselves. But it CAN be
honoured for the one part of this phase that is genuinely a correctness risk rather than a
performance risk: **the comparison**. If the comparison is too strict it never fires and the
timeout persists (annoying, self-announcing). If it is too loose it silently discards the user's
ingredient edits (dangerous, silent). Isolating that logic as a pure function is what makes it
testable at all, and this plan tests it against the real file text — not a copy, not a mock.

A free second benefit: evaluating the whole `adminApi.gs` source in the harness turns `npm test`
into a syntax check for a 4,116-line file that currently has none. Today a stray typo in that file
is only discovered when the owner redeploys.

Output: `tests/frontend/adminapi-recipe-pure.test.js` (new) plus four pure functions in
`apps-script/adminApi.gs`. **No behaviour of `updateRecipe` changes in this plan** — the helpers
are added but not yet called. Wiring happens in 79-03, so that every `.gs` edit lands before the
single owner redeploy in 79-04.
</objective>

Four new pure functions in `apps-script/adminApi.gs` (place them immediately after
`generateNextId`, which ends at line 1263, so the id-related helpers sit together):

  formatPaddedId(prefix, num, padLength) -> string
    Zero-pads `num` to `padLength` digits and prefixes it. Mirrors generateNextId's own
    padding loop (adminApi.gs:1260-1262). Numbers longer than padLength are NOT truncated.

  maxIdNumFromColumn(dataRows, colIndex, prefix) -> number
    Given already-fetched 2D data rows (NO header row), returns the highest integer suffix
    among cells in `colIndex` that start with `prefix`. Returns 0 when none match.
    Mirrors generateNextId's scan loop (adminApi.gs:1253-1259) but over a passed-in array.

  normalizeRecipeIngredientTuple(itemId, quantity, unit) -> string
    Canonical comparison key for one ingredient row.

  recipeIngredientsUnchanged(incomingTuples, storedTuples) -> boolean
    Order-sensitive, length-sensitive element-wise comparison of two arrays of tuple keys.

Existing helper the harness also exposes (already at adminApi.gs:3329):
  sanitizeInput(input) -> string

Existing constants the harness may reference:
  RECIPE_INGREDIENTS_SHEET_NAME = 'RecipeIngredients'  (adminApi.gs:58)

RecipeIngredients column order (D-15, fixed):
  0 ingredient_id | 1 recipe_id | 2 item_id | 3 item_name | 4 quantity | 5 unit

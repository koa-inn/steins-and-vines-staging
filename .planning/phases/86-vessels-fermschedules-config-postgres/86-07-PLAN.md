<interfaces>
lib/staff-access.js (consumed by 86-12 routes/auth.js, lib/authTiers.js, routes/staff-access.js):
- getMode() -> storeFlag.resolveStoreMode('STAFF_ACCESS_STORE') (lazy require)
- breakGlassEmails() -> lower-cased, trimmed, non-empty entries of process.env.STAFF_EMAILS (same parse as routes/auth.js L94-96)
- resolve(email, {bypassCache}) -> Promise<{allowed:Boolean, role:'owner'|'staff'|null, source:'env'|'pg'|'none', breakGlass:Boolean, degraded:Boolean}>; never rejects
  sheets:   env member -> {allowed:true, role:'owner', source:'env', breakGlass:true}; else {allowed:false, role:null, source:'none'}
  dual/pg:  env member -> lookup role; row -> role from row, source 'pg'; no row -> 'owner', source 'env'; PG error -> 'owner', degraded:true (allowed: break-glass)
            non-env  -> row -> {allowed:true, role}; no row -> denied; PG error -> denied, degraded:true, log.warn('[staff-access] lookup failed h=' + hashEmail(email))
  Positive results cached <= 5000 ms keyed by normalised email; bypassCache skips read AND write.
- clearCache() -> empties the cache (called after every mutation by 86-12 routes)
- hashEmail(email) -> first 10 hex chars of sha256(normalised email)
- PG leg uses db.query('select role from staff_access where email = $1', [email]) with no fallback to sheets.

lib/staff-access-pg.js (client from db.withTransaction; business rejections resolve {ok:false,error,message}):
- listStaff(client) -> [{email, role, added_by, added_at, updated_by, updated_at}] ordered by role desc, email
- getRole(client, email) -> 'owner'|'staff'|null
- addStaff(client, {actor, target, role, breakGlass}) -> {ok:true} | invalid_email | invalid_role | staff_exists
- changeRole(client, {actor, target, role, breakGlass}) -> {ok:true} | cannot_change_own_role | break_glass_member | not_found | last_owner | invalid_role
- removeStaff(client, {actor, target, breakGlass}) -> {ok:true, role_before} | cannot_remove_self | break_glass_member | not_found | last_owner
- recordDenied(client, {actor, target, note}) -> inserts action 'denied'
- listAudit(client, {limit}) -> newest first, limit <= 200
breakGlass = array from staffAccess.breakGlassEmails() passed in by the caller (keeps this module env-free).
Effective owners (computed under `select email, role from staff_access where role = 'owner' or email = any($1) for update`, $1 = breakGlass):
  PG owner rows ∪ break-glass emails that have NO staff_access row, minus the target.
</interfaces>

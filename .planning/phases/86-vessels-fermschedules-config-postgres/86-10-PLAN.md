- POST /api/vessels {vessel_id, label, type, material, capacity_liters, bottom_diameter_cm, top_diameter_cm, depth_cm, location, brand, notes} -> 201 {ok:true, vessel} | 409 {error, code:'vessel_exists'} | 422 {error, code:'invalid_vessel'}
- PUT  /api/vessels/:id {same fields minus vessel_id, status, expected_updated_at} -> 200 {ok:true, vessel} | 409 {error, code:'stale_vessel'} | 422 {error, code:'invalid_vessel'|'vessel_id_immutable'}
- POST /api/vessels/:id/archive {expected_updated_at} -> 200 {ok:true, vessel} | 409 code 'stale_vessel'|'vessel_in_use'
- POST /api/vessels/:id/unarchive {expected_updated_at} -> 200 {ok:true, vessel} | 409 'stale_vessel'

Staff Access API (implemented in 86-12; session tier via x-session-token header only):
- GET    /api/staff-access/me -> {email, role:'owner'|'staff', break_glass:Boolean, store:'sheets'|'dual'|'postgres'}
- GET    /api/staff-access -> {ok:true, staff:[{email, role, added_by, added_at, break_glass}], break_glass_only:[email], audit:[{occurred_at, actor_email, target_email, action, role_before, role_after}]}
- POST   /api/staff-access {email, role} -> 201 {ok:true}
- PUT    /api/staff-access/:email {role} -> {ok:true}
- DELETE /api/staff-access/:email -> {ok:true}
  errors: 403 {code:'owner_required'}, 409 {error, code:'cannot_remove_self'|'cannot_change_own_role'|'last_owner'|'break_glass_member'|'staff_exists'}, 422 {code:'invalid_email'|'invalid_role'}, 503 {code:'staff_access_requires_postgres'|'staff_access_unavailable'}

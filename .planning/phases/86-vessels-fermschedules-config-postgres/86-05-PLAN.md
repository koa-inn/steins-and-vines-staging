<interfaces>
Module contract (copy lib/recipe-pg.js L1-20 conventions): never requires pg; every function takes
`client` from db.withTransaction; $n placeholders only; SQL in module-level constants; business
rejections RESOLVE {ok:false, error, message}; infra errors propagate (tx rolls back); underscore keys
(_vesselId) are for the facade/mirror and are stripped there.

VESSEL_SHEET_COLUMNS (sheet order): vessel_id, type, material, capacity_liters, status,
  bottom_diameter_cm, top_diameter_cm, depth_cm, location, brand, notes
Extra serialized keys: label, archived (boolean), updated_at (ISO ms), position (number)
NUMERIC: capacity_liters, bottom_diameter_cm, top_diameter_cm, depth_cm

Signatures (consumed by 86-11 ops-mirror, 86-13 vessel-store, 86-15 routes):
- listVessels(client) -> Promise<Array<VesselObject>>  (all rows, position asc)
- getVessel(client, vesselId) -> Promise<VesselObject|null>
- createVessel(client, payload, {actor, now}) -> {ok:true, vessel_id, vessel, _vesselId} | {ok:false, error:'invalid_vessel_id'|'vessel_exists'|'missing_fields'|'invalid_status'|'invalid_number', message}
- updateVessel(client, vesselId, payload, {actor, now, expectedUpdatedAt}) -> {ok:true, vessel, _vesselId} | {ok:false, error:'not_found'|'stale_vessel'|'vessel_id_immutable'|'invalid_status'|'invalid_number', message}
- archiveVessel / unarchiveVessel(client, vesselId, {actor, now, expectedUpdatedAt}) -> {ok:true, vessel, _vesselId} | {ok:false, error:'not_found'|'stale_vessel'|'vessel_in_use', message}
- applyStatusChanges(client, changes, {actor, now}) -> {applied:[id], unchanged:[id], unknown:[id], invalid:[id]}
- nextVesselNumber(client, prefix) -> 'PREFIX-NNN' (3-digit pad, max existing suffix + 1; prefix must match ^[A-Z]{2,6}$)
STALE message: 'This vessel was changed since you opened it — reload to see the latest'
</interfaces>

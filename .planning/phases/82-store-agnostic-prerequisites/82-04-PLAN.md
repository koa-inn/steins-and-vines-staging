<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Staff browser → /api/admin/proxy | Untrusted request body (action + params) crosses here |
| Middleware → Apps Script | Middleware holds APPS_SCRIPT_SERVER_TOKEN; Apps Script trusts it fully for reads (no read allowlist, Pitfall 3) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-82-04-01 | Elevation of Privilege | action passthrough | mitigate | Hardcoded ADMIN_PANEL_PROXY_ACTIONS checked before any axios call; closed 400 default; excluded-action tests (incl. get_gift_cards, get_waitlist, check_auth) — this is the ONLY read allowlist since doGet's server_token path has none |
| T-82-04-02 | Spoofing | client-supplied token / server_token | mitigate | `delete payload.token`; server_token always overwritten from env; identity only from requireTiers(['legacy','session']) (D-06) |
| T-82-04-03 | Elevation of Privilege | kiosk device token reaching admin data | mitigate | requireTiers excludes 'device'; test asserts rejection |
| T-82-04-04 | Information Disclosure | error details leaking upstream internals | mitigate | Upstream failures collapse to {ok:false,error:'server_error'}; message logged server-side only |
| T-82-04-05 | Tampering | proxy-collapsed 502 hides an applied write | transfer | Client-side rule (82-06, D-08): writes never retried |
| T-82-04-06 | Denial of Service | proxy amplifying load on Apps Script | accept | Global apiLimiter already covers /api; staff-only surface |
</threat_model>

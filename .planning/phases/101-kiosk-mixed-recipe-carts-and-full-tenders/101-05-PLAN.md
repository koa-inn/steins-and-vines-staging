| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-101-13 | Tampering | recipes[] price/total fields | mitigate | validateRecipeEntries copies parameters only; server re-prices from recipe-store + ingredient catalog; client_grand_total REQUIRED for recipe carts and asserted (blocking, >0.01 -> 400 pre-charge) |

| T-101-16 | Denial of Service | recipes array amplification | mitigate | MAX_RECIPE_ENTRIES 25, existing 50-item cap, 1 MB body limit, one ingredient-catalog load, zero Zoho calls for recipes |
| T-101-17 | Elevation | stock override | accept | Business rule: negative stock is an intentional oversell override; override logged via kiosk.stock_override event (no PII) |
| T-101-18 | Spoofing | recipe gate | mitigate | BEER_SALES_ENABLED checked server-side before pricing (403) |
| T-101-19 | Denial of Service | fee item missing from kiosk catalog | mitigate | isUsable requires fee ids (Pitfall 4); unresolved fee tax fails closed pre-charge |

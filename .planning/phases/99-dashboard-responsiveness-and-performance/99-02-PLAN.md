    dashCacheUsable(entry, todayYmd, email) → entry or null (D-08):
    - null/undefined/non-object, v !== 1, missing dashData object → null
    - entry.day !== todayYmd → null; late-evening PT case: entry.day '2026-11-06', todayYmd computed for 2026-11-07T06:30:00Z (= 22:30 PT on Nov 6) is '2026-11-06' → usable; for 2026-11-07T08:30:00Z (00:30 PT Nov 7) → null
    - entry.email missing, email missing, or entry.email !== email → null (strict same-user)

    dashAsOfHint(state, savedAtMs) → string, time as h:mm AM/PM in America/Vancouver (toLocaleTimeString 'en-US', hour 'numeric', minute '2-digit'):
    - 'updating' → 'As of 3:05 PM · Updating…' (U+00B7 middle dot, U+2026 ellipsis)
    - 'fresh' → 'Updated 3:05 PM'
    - 'failed' → "As of 3:05 PM · Couldn't refresh. Reopen the Dashboard tab to try again."
    - any other state or non-finite savedAtMs → ''
    - no output contains 'stale', 'conflict', 'missing' or 'late' (banned words, case-insensitive)

    dashPointStyleFor(seriesKey, index) → {pointStyle, pointRadius:6, pointHitRadius:22} (D-15, UI-SPEC §3):
    - 'wine' circle, 'cider' triangle, 'beer' rect, 'other' rectRot (case-insensitive key)
    - unknown key: by index cycling circle, triangle, rect, rectRot, cross, star (index 6 → circle)

    dashMarkerGlyph(pointStyle) → legend glyph: circle '●', triangle '▲', rect '■', rectRot '◆', cross '✚', star '★', anything else '■'.

    dashTouchTapAction(prevPoint, nextPoint, tooltipOpen) → 'show' | 'drill' | 'hide' (D-13). Points are {datasetIndex, index} or null:
    - nextPoint null → 'hide'
    - tooltipOpen true and prevPoint equals nextPoint (both fields) → 'drill'
    - otherwise → 'show' (first tap, a different point, or tooltip closed)

    - sectionKey 'today' → true always
    - isPhone true → sectionOpen === true
    - isPhone false → ioSupported !== true || intersected === true

    dashSectionCountLabel(n) → '1 chart' for 1, 'N charts' otherwise (0 → '0 charts').

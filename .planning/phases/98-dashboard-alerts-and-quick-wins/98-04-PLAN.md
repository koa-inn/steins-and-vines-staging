## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| get_dashboard_stats / get_tasks_upcoming / get_waitlist payloads → dashboard DOM | Server data rendered into chips (counts, fixed labels) |
| BrewPad browser → admin proxy → Apps Script get_waitlist | Existing staff-gated read, now also called from the dashboard |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-98-11 | Tampering (XSS) | renderDashV2Attention | mitigate | Labels and aria via escapeHTML; data-attn values are fixed model keys; counts are numbers; no server string reaches innerHTML unescaped |
| T-98-12 | Information disclosure | _dashWaitlist | mitigate | Only the integer count is retained in dashboard state; waitlist rows (emails) are not stored or rendered by the dashboard |
| T-98-13 | Denial of service | get_waitlist from dashboard | mitigate | Once per _dashLoadTime with token guard (no polling of its own); Apps Script, not Zoho, so the shared 1,000/day Zoho quota is untouched |
| T-98-14 | Repudiation / abuse | invite sending | mitigate | No new send path or button; session override only flips a local flag after the existing confirm-sheet send succeeds (F9) |
| T-98-15 | Spoofing | false all-clear | mitigate | allClear requires every source settled 'ok'; tests cover loading and failed states |
</threat_model>
